# Changelog

## [1.2.0] - 2026-08-31

### Added
- Initial release of Lavender Theme
- Three themes included:
  - 🌌 Lavender Dark 1
  - 🌙 Lavender Dark 2
  - ☁️ Lavender Light
- Support for multiple languages:
  - TypeScript, JavaScript, React/TSX
  - Python, Go, Rust, C/C++
  - C#, Java, PHP, Ruby
  - Dart/Flutter, Swift
  - SQL, JSON, YAML
  - HTML, CSS/SCSS/LESS
  - Markdown
- Semantic highlighting support
- Git decorations integration
- Terminal styling
- Full VS Code workbench theming

### Features
- Soft lavender and purple color palette
- High contrast for readability
- Aesthetic and cozy design
- Optimized for long coding sessions
