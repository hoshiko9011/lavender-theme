## 💜 About

**Lavender Theme** is a collection of soft and aesthetic purple themes made for **Visual Studio Code**.

It is designed for developers who enjoy a cozy, clean and relaxing coding environment with beautiful lavender and purple colors.

Whether you prefer a deep dark editor or a gentle light interface, Lavender Purple Theme has something for you. 💜

## 🚀 Installation

### Option 1: Visual Studio Marketplace (Recommended)

1. Open **Visual Studio Code**
2. Go to Extensions (`Ctrl+Shift+X` or `Cmd+Shift+X`)
3. Search for **"Lavender Theme"**
4. Click **Install**
5. Press `Ctrl+Shift+P` or `Cmd+Shift+P`
6. Type **"Preferences: Color Theme"**
7. Select your favorite **Lavender Theme**
