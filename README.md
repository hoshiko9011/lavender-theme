## Themes

| Name | Mode | Character |
| --- | --- | --- |
| **Lavender Dark 1** | Dark | Deep, low-contrast chrome, cool lilac accents |
| **Lavender Dark 2** | Dark | Brighter text, softer lavender surfaces |
| **Lavender Light** | Light | Paper-like background, violet structure |

All three share the same token system so switching variants does not rearrange the meaning of colors.

---

## Features

- Full VS Code UI coverage (editor, sidebar, terminal, widgets)
- Semantic highlighting enabled
- Syntax scopes for common languages: TypeScript, JavaScript, Python, Go, Rust, Java, C#, C/C++, PHP, Ruby, Kotlin, Swift, Dart/Flutter, SQL, Shell, HTML/CSS, JSON/YAML, Markdown, Vue/Svelte, GraphQL
- Comfortable contrast for extended reading

## Install

### Marketplace

1. Open Extensions in VS Code (`Ctrl+Shift+X` / `Cmd+Shift+X`)
2. Search for **Lavender Theme**
3. Install, then open the Command Palette
4. Run **Preferences: Color Theme** and choose a Lavender variant

### From source

```bash
git clone https://github.com/hoshiko9011/lavender-theme.git
cd lavender-theme
```

Then load the folder as a development extension, or package it with `vsce`.
